## What I built

There was no existing repo here (just `.claude/skills`), so I built a standalone, reusable CLI tool rather than a one-off fix: `fix_failing_test.py`, backed by `test_fix_failing_test.py`.

**Why an agent loop, not a fixed script:** I checked this against the `agent-vs-workflow-decision` skill first. Fixing an arbitrary failing test clears all four bars for "agent" — the number of edits needed is unknowable up front, `run_tests` gives real ground truth (not the model's own assertion), the problem space is bounded (one repo, one test), and mistakes are recoverable via git. So it's a loop with hard stopping conditions, not a scripted pipeline.

**Usage:**
```
ANTHROPIC_API_KEY=... python fix_failing_test.py --repo path/to/repo \
    --test-cmd "pytest tests/test_foo.py::test_bar -q"
```

**How it works:**
- Tools: `run_tests` (ground truth), `list_files`, `read_file`, `edit_file` (exact old_string→new_string, refuses ambiguous or missing matches), `record_plan` (so its reasoning lands in the transcript, not just its head).
- Stopping conditions: max iterations (15), max cost ($2, priced off real token usage), wall-clock timeout (600s), and stuck-call detection (same tool + args 3x triggers an in-band nudge before returning `stuck`).
- Safety: refuses to run against a dirty git working tree unless `--allow-dirty` (so a bad run is one `git checkout -- .` away from undone), and every file tool path-checks against traversal outside the repo.
- **It doesn't trust the model's word.** When the model says "done" with no more tool calls, the harness independently re-runs the test command itself before reporting pass/fail.

**Verified:** 22 offline unit tests (path-traversal guard, edit_file's exact/ambiguous/replace_all behavior, budget/stuck logic, git-dirty gate) all pass — no API key needed for these. I also hand-verified the CLI's two safety gates (missing key, dirty tree) against a scratch repo. I could not run a full live loop end-to-end because no `ANTHROPIC_API_KEY` is set in this environment — that's the one thing I couldn't demonstrate rather than fabricate.

One thing worth flagging: pricing constants (`PRICE_IN_PER_M`/`PRICE_OUT_PER_M`) and `MODEL` are hardcoded near the top and should be checked against current published rates before trusting the cost cap for real budget enforcement.

#!/usr/bin/env python3
"""
fix_failing_test.py — point it at a repo and a failing-test command; it loops
an LLM agent (read file, edit file, run tests) until the test passes, a
budget runs out, or it gets stuck. Ground truth at every step is a real
`run_tests` call — the model's own claim that it's "done" is verified
independently before being reported as a pass.

Usage:
    python fix_failing_test.py --repo path/to/repo \
        --test-cmd "pytest tests/test_foo.py::test_bar -q"

    python fix_failing_test.py --repo . --test-cmd "npm test -- foo.spec.js"

Requires ANTHROPIC_API_KEY in the environment.
"""
from __future__ import annotations

import json

# Verify against current published pricing before relying on this for real budgets.
PRICE_IN_PER_M = 3.00
PRICE_OUT_PER_M = 15.00

MAX_TOOL_OUTPUT_CHARS = 8_000
MAX_FILES_LISTED = 200


# --------------------------------------------------------------------------
# Budget / stopping conditions
# --------------------------------------------------------------------------

@dataclass
class Budget:
    max_iterations: int = 15
    max_cost_usd: float = 2.00
    max_wall_clock_s: float = 600.0


@dataclass
class RunState:
    iterations: int = 0
    cost_usd: float = 0.0
    started: float = field(default_factory=time.monotonic)
    call_signatures: Counter = field(default_factory=Counter)
    tool_log: list = field(default_factory=list)

    def elapsed(self) -> float:
        return time.monotonic() - self.started


def check_budget(state: RunState, budget: Budget) -> str | None:
    if state.iterations >= budget.max_iterations:
        return "max_iterations"
    if state.cost_usd >= budget.max_cost_usd:
        return "budget_exceeded"
    if state.elapsed() >= budget.max_wall_clock_s:
        return "timeout"
    if max(state.call_signatures.values(), default=0) >= 3:
        return "stuck"
    return None


def price(usage) -> float:
    return (usage.input_tokens / 1e6) * PRICE_IN_PER_M + \
           (usage.output_tokens / 1e6) * PRICE_OUT_PER_M


# --------------------------------------------------------------------------
# Sandbox / path safety
# --------------------------------------------------------------------------

class PathEscapeError(Exception):
    pass


def safe_path(repo_root: Path, rel_path: str) -> Path:
    """Resolve rel_path against repo_root and refuse anything that escapes it."""
    candidate = (repo_root / rel_path).resolve()
    repo_root = repo_root.resolve()
    if repo_root != candidate and repo_root not in candidate.parents:
        raise PathEscapeError(
            f"{rel_path!r} resolves outside the repo ({candidate}); refusing."
        )
    return candidate


def truncate(text: str, limit: int = MAX_TOOL_OUTPUT_CHARS) -> str:
    if len(text) <= limit:
        return text
    return text[:limit] + f"\n... [truncated, {len(text) - limit} more chars]"


# --------------------------------------------------------------------------
# Tools — every one is either a real environment signal (run_tests, read_file,
# list_files) or a mechanical edit the tests will independently verify.
# --------------------------------------------------------------------------

class Tools:
    def __init__(self, repo_root: Path, test_cmd: str):
        self.repo_root = repo_root
        self.test_cmd = test_cmd
        self.files_touched: set[str] = set()

    def run_tests(self) -> dict:
        """Ground truth. Runs the configured test command and reports the real result."""
        try:
            proc = subprocess.run(
                self.test_cmd,
                cwd=self.repo_root,
                shell=True,
                capture_output=True,
                text=True,
                timeout=120,
            )
        except subprocess.TimeoutExpired:
            return {"passed": False, "error": "test command timed out after 120s"}
        return {
            "passed": proc.returncode == 0,
            "exit_code": proc.returncode,
            "stdout": truncate(proc.stdout),
            "stderr": truncate(proc.stderr),
        }

    def list_files(self, pattern: str = "**/*") -> dict:
        matches = []
        truncated = False
        for p in self.repo_root.glob(pattern):
            if not p.is_file():
                continue
            if any(part in {".git", "node_modules", "__pycache__", ".venv"} for part in p.parts):
                continue
            if len(matches) >= MAX_FILES_LISTED:
                truncated = True
                break
            matches.append(p.relative_to(self.repo_root).as_posix())
        return {"files": sorted(matches), "truncated": truncated}

    def read_file(self, path: str) -> dict:
        try:
            full = safe_path(self.repo_root, path)
        except PathEscapeError as e:
            return {"error": str(e)}
        if not full.is_file():
            return {"error": f"{path!r} is not a file"}
        text = full.read_text(errors="replace")
        numbered = "\n".join(f"{i + 1}\t{line}" for i, line in enumerate(text.splitlines()))
        return {"path": path, "content": truncate(numbered)}

    def edit_file(self, path: str, old_string: str, new_string: str, replace_all: bool = False) -> dict:
        try:
            full = safe_path(self.repo_root, path)
        except PathEscapeError as e:
            return {"error": str(e)}
        if not full.is_file():
            return {"error": f"{path!r} is not a file"}
        if old_string == new_string:
            return {"error": "old_string and new_string are identical"}
        text = full.read_text(errors="replace")
        count = text.count(old_string)
        if count == 0:
            return {"error": "old_string not found in file — it must match exactly, including whitespace"}
        if count > 1 and not replace_all:
            return {"error": f"old_string matches {count} locations; pass replace_all=true or narrow the match"}
        new_text = text.replace(old_string, new_string) if replace_all else text.replace(old_string, new_string, 1)
        full.write_text(new_text)
        self.files_touched.add(path)
        return {"ok": True, "path": path, "replacements": count if replace_all else 1}

    def record_plan(self, steps: list[str], success_criteria: str) -> dict:
        return {"recorded": True}

SYSTEM_PROMPT = """You are fixing a failing test in a real repository. You have tools to \
list files, read files, make exact-match edits, and run the test command. run_tests is the \
only source of truth — the user cannot see your reasoning, only whether the test passes.

Rules:
- Call record_plan before your first edit, and again if your plan changes.
- Read a file before editing it; edit_file requires old_string to match exactly.
- Prefer the smallest edit that fixes the actual bug. Do not change the test's assertions to \
make it pass unless the test itself is factually wrong (wrong expected value, typo) — the goal \
is to fix the code under test, not to weaken the check.
- Call run_tests after every edit. Do not claim the task is done without a passing run_tests call.
- If you're stuck, say what you tried and why it didn't work rather than repeating the same edit."""


# --------------------------------------------------------------------------
# The loop
# --------------------------------------------------------------------------

def run_tool(tools: Tools, block, state: RunState) -> dict:
    signature = (block.name, json.dumps(block.input, sort_keys=True))
    state.call_signatures[signature] += 1

    if state.call_signatures[signature] == 3:
        return {
            "type": "tool_result",
            "tool_use_id": block.id,
            "content": json.dumps({
                "error": "You already called this tool with these exact arguments twice and "
                         "got the same result. Try a different approach, a different file, or "
                         "explain what's blocking you instead of repeating this call."
            }),
            "is_error": True,
        }

    method = getattr(tools, block.name, None)
    if method is None:
        result: dict[str, Any] = {"error": f"No tool named {block.name!r}"}
        is_error = True
    else:
        try:
            result = method(**block.input)
            is_error = bool(result.get("error"))
        except Exception as e:
            result = {"error": f"{type(e).__name__}: {e}"}
            is_error = True

    state.tool_log.append({
        "iteration": state.iterations,
        "name": block.name,
        "args": block.input,
        "ok": not is_error,
    })

    return {
        "type": "tool_result",
        "tool_use_id": block.id,
        "content": json.dumps(result),
        "is_error": is_error,
    }


def run(repo_root: Path, test_cmd: str, budget: Budget, client: anthropic.Anthropic) -> dict:
    tools = Tools(repo_root, test_cmd)
    state = RunState()

    initial = tools.run_tests()
    if initial.get("passed"):
        return {"status": "already_passing", "iterations": 0, "cost_usd": 0.0, "files_touched": []}

    goal = (
        f"The test command `{test_cmd}` is currently failing in this repo. "
        f"Here is the current output:\n\nSTDOUT:\n{initial.get('stdout', '')}\n\n"
        f"STDERR:\n{initial.get('stderr', '')}\n\n"
        "Find the cause and fix it. Use your tools; do not guess without reading the relevant code."
    )
    messages = [{"role": "user", "content": goal}]

    while True:
        stop = check_budget(state, budget)
        if stop:
            return _finish(stop, tools, state)

        response = client.messages.create(
            model=MODEL,
            max_tokens=4096,
            system=SYSTEM_PROMPT,
            tools=TOOL_SCHEMAS,
            messages=messages,
        )
        state.iterations += 1
        state.cost_usd += price(response.usage)
        messages.append({"role": "assistant", "content": response.content})

        stop = check_budget(state, budget)
        if stop:
            return _finish(stop, tools, state)

        if response.stop_reason != "tool_use":
            # The model thinks it's done. Do not trust that — verify independently.
            return _finish("model_done", tools, state)

        results = [run_tool(tools, b, state) for b in response.content if b.type == "tool_use"]
        messages.append({"role": "user", "content": results})


def _finish(reason: str, tools: Tools, state: RunState) -> dict:
    final = tools.run_tests()
    return {
        "status": "passed" if final.get("passed") else "failed",
        "stop_reason": reason,
        "iterations": state.iterations,
        "cost_usd": round(state.cost_usd, 4),
        "elapsed_s": round(state.elapsed(), 1),
        "files_touched": sorted(tools.files_touched),
        "final_test_result": final,
        "tool_log": state.tool_log,
    }


# --------------------------------------------------------------------------
# Git safety net
# --------------------------------------------------------------------------

def git_dirty(repo_root: Path) -> bool | None:
    """True if dirty, False if clean, None if not a git repo."""
    proc = subprocess.run(
        ["git", "status", "--porcelain"], cwd=repo_root,
        capture_output=True, text=True,
    )
    if proc.returncode != 0:
        return None
    return bool(proc.stdout.strip())


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--repo", required=True, help="Path to the repo containing the failing test.")
    parser.add_argument("--test-cmd", required=True, help="Shell command that runs the failing test, e.g. 'pytest tests/test_foo.py -q'.")
    parser.add_argument("--max-iterations", type=int, default=15)
    parser.add_argument("--max-cost-usd", type=float, default=2.00)
    parser.add_argument("--max-wall-clock-s", type=float, default=600.0)
    parser.add_argument("--allow-dirty", action="store_true", help="Proceed even if the git working tree has uncommitted changes.")
    parser.add_argument("--log-file", help="Write the structured run log as JSON to this path.")
    args = parser.parse_args()

    repo_root = Path(args.repo).resolve()
    if not repo_root.is_dir():
        print(f"error: {repo_root} is not a directory", file=sys.stderr)
        return 2

    dirty = git_dirty(repo_root)
    if dirty is None:
        print(f"warning: {repo_root} is not a git repo — edits cannot be reverted automatically.", file=sys.stderr)
    elif dirty and not args.allow_dirty:
        print(
            "error: git working tree has uncommitted changes. Commit or stash them first "
            "(so a bad run can be reverted with `git checkout -- .`), or pass --allow-dirty.",
            file=sys.stderr,
        )
        return 2

    if not os.environ.get("ANTHROPIC_API_KEY"):
        print("error: ANTHROPIC_API_KEY is not set.", file=sys.stderr)
        return 2

    client = anthropic.Anthropic()
    budget = Budget(
        max_iterations=args.max_iterations,
        max_cost_usd=args.max_cost_usd,
        max_wall_clock_s=args.max_wall_clock_s,
    )

    result = run(repo_root, args.test_cmd, budget, client)

    print(json.dumps({k: v for k, v in result.items() if k != "tool_log"}, indent=2))
    if args.log_file:
        Path(args.log_file).write_text(json.dumps(result, indent=2))

    if result["status"] in ("passed", "already_passing"):
        return 0
    return 1


if __name__ == "__main__":
    sys.exit(main())
