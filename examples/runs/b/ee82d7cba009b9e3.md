## Summary

Built `test_fixer_agent/fixer.py` — a CLI agent that takes a failing test in any repo and tries to get it passing. Since a failing-test agent has an unpredictable number of steps but real ground truth at each one (the test either passes or it doesn't), I built it as a manual agent loop rather than a fixed workflow, per the agent-vs-workflow decision framework.

**Usage:**
```bash
python fixer.py --repo /path/to/repo --test-cmd "pytest tests/test_foo.py::test_bar -q"
```

**How it works:** confirms the test actually fails → creates a git branch (refuses a dirty tree) → loops: read files, make a minimal edit, rerun the real test command, read the real output, repeat — until `run_tests` reports exit code 0 or a budget caps it (15 iterations / $2 / 10 min by default, plus stuck-loop detection). Tool surface is narrow by design: `list_files`, `read_file`, `edit_file` (exact string replace), `create_file`, `run_tests`, `record_plan` — no shell/bash tool, no delete, and every file path is contained to the repo root. Success is never the model's own assertion, only a real passing test run. Writes a structured JSON run log each time.

**Verified:** syntax-checked, ran end-to-end against `demo_repo/` (an included toy repo with a genuinely failing pytest test) — baseline detection, dirty-tree refusal, git branch creation, and clean error handling for missing credentials all confirmed working. Unit-tested the tool executors directly against real files: read, edit (unique-match and replace_all), create-with-dup-rejection, and path-traversal/absolute-path blocking all passed, and applying the actual one-line fix via `edit_file` made the real pytest test pass.

One thing I couldn't verify live: the actual LLM-driven loop, since no `ANTHROPIC_API_KEY` or `ant` profile is configured in this sandbox — the harness now fails cleanly with a clear message at that point instead of a raw traceback. Once you set credentials, `demo_repo/` is ready to try immediately.

Agent that takes a failing test in a repo and tries to get it passing.

Usage:
    python fixer.py --repo /path/to/repo --test-cmd "pytest tests/test_foo.py::test_bar -q"

The agent loop is manual (not the SDK's beta tool_runner) so that iteration
caps, cost caps, wall-clock caps, and stuck-loop detection are all explicit
and enforced by this code, not left to model behavior. Ground truth at every
step comes from actually running the test command, never from the model's
own assertion that it's done.

    "claude-opus-5": (5.00, 25.00),
    "claude-sonnet-5": (2.00, 10.00),
    "claude-haiku-4-5": (1.00, 5.00),

@dataclass
class Budget:
    max_iterations: int = 15
    max_cost_usd: float = 2.00
    max_wall_clock_s: float = 600.0


@dataclass
class RunState:
    iterations: int = 0
    cost_usd: float = 0.0
    started: float = field(default_factory=time.monotonic)
    call_signatures: Counter = field(default_factory=Counter)
    tool_call_log: list = field(default_factory=list)
    plan_revisions: int = 0

    def elapsed(self) -> float:
        return time.monotonic() - self.started


def check_budget(state: RunState, budget: Budget) -> str | None:
    if state.iterations >= budget.max_iterations:
        return "max_iterations"
    if state.cost_usd >= budget.max_cost_usd:
        return "budget_exceeded"
    if state.elapsed() >= budget.max_wall_clock_s:
        return "timeout"
    if max(state.call_signatures.values(), default=0) >= 3:
        return "stuck"
    return None


def price(model: str, usage) -> float:
    price_in, price_out = PRICES_PER_MTOK.get(model, PRICES_PER_MTOK["claude-opus-5"])
    cost = (usage.input_tokens / 1e6) * price_in + (usage.output_tokens / 1e6) * price_out
    cache_read = getattr(usage, "cache_read_input_tokens", None) or 0
    cache_creation = getattr(usage, "cache_creation_input_tokens", None) or 0
    cost += (cache_read / 1e6) * price_in * 0.1
    cost += (cache_creation / 1e6) * price_in * 1.25
    return cost

class PathEscapeError(Exception):

def resolve_in_repo(repo_root: Path, rel_path: str) -> Path:
    if Path(rel_path).is_absolute():
        raise PathEscapeError(f"path must be relative to the repo root, got absolute path: {rel_path}")
    candidate = (repo_root / rel_path).resolve()
    try:
        candidate.relative_to(repo_root.resolve())
    except ValueError:
        raise PathEscapeError(f"path '{rel_path}' resolves outside the repo root")
    return candidate


def truncate(text: str, limit: int = MAX_RESULT_CHARS) -> str:
    if len(text) <= limit:
        return text
    return text[:limit] + f"\n... [truncated, {len(text) - limit} more characters]"

class ToolExecutor:
    def __init__(self, repo_root: Path, test_cmd: str, test_timeout: float):
        self.repo_root = repo_root
        self.test_cmd = test_cmd
        self.test_timeout = test_timeout
        self.last_test_exit_code: int | None = None

    def list_files(self, pattern: str = "**/*", max_results: int = 200) -> dict:
        matches = []
        for p in self.repo_root.glob(pattern):
            if ".git" in p.parts:
                continue
            if p.is_file():
                matches.append(str(p.relative_to(self.repo_root)).replace("\\", "/"))
            if len(matches) >= max_results:
                break
        return {"files": sorted(matches), "count": len(matches)}

    def read_file(self, path: str, offset: int = 1, limit: int = 2000) -> dict:
        target = resolve_in_repo(self.repo_root, path)
        if not target.is_file():
            return {"error": f"no such file: {path}"}
        lines = target.read_text(encoding="utf-8", errors="replace").splitlines()
        start = max(offset - 1, 0)
        chunk = lines[start:start + limit]
        return {
            "content": truncate("\n".join(chunk)),
            "total_lines": len(lines),
            "returned_lines": f"{start + 1}-{start + len(chunk)}",
        }

    def edit_file(self, path: str, old_string: str, new_string: str, replace_all: bool = False) -> dict:
        target = resolve_in_repo(self.repo_root, path)
        if not target.is_file():
            return {"error": f"no such file: {path}"}
        text = target.read_text(encoding="utf-8", errors="replace")
        count = text.count(old_string)
        if count == 0:
            return {"error": "old_string not found in file -- read the file again and copy the exact text"}
        if count > 1 and not replace_all:
            return {"error": f"old_string is not unique ({count} occurrences) -- add more context or set replace_all"}
        new_text = text.replace(old_string, new_string) if replace_all else text.replace(old_string, new_string, 1)
        target.write_text(new_text, encoding="utf-8")
        return {"ok": True, "replacements": count if replace_all else 1}

    def create_file(self, path: str, content: str) -> dict:
        target = resolve_in_repo(self.repo_root, path)
        if target.exists():
            return {"error": f"file already exists: {path} -- use edit_file instead"}
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(content, encoding="utf-8")
        return {"ok": True}

    def run_tests(self) -> dict:
        try:
            proc = subprocess.run(
                self.test_cmd,
                shell=True,
                cwd=self.repo_root,
                capture_output=True,
                text=True,
                timeout=self.test_timeout,
            )
            self.last_test_exit_code = proc.returncode
            return {
                "exit_code": proc.returncode,
                "stdout": truncate(proc.stdout),
                "stderr": truncate(proc.stderr),
            }
        except subprocess.TimeoutExpired:
            self.last_test_exit_code = None
            return {"error": f"test command timed out after {self.test_timeout}s"}

    def record_plan(self, steps: list, success_criteria: str) -> dict:
        return {"ok": True, "logged": True}

    def dispatch(self, name: str, tool_input: dict) -> dict:
        handler = {
            "list_files": self.list_files,
            "read_file": self.read_file,
            "edit_file": self.edit_file,
            "create_file": self.create_file,
            "run_tests": self.run_tests,
            "record_plan": self.record_plan,
        }.get(name)
        if handler is None:
            return {"error": f"unknown tool: {name}"}
        try:
            return handler(**tool_input)
        except PathEscapeError as e:
            return {"error": str(e)}
        except TypeError as e:
            return {"error": f"bad arguments for {name}: {e}"}


# --------------------------------------------------------------------------
# Git safety (sandbox on a branch; refuse a dirty tree)
# --------------------------------------------------------------------------

def git(repo_root: Path, *args: str) -> subprocess.CompletedProcess:
    return subprocess.run(["git", *args], cwd=repo_root, capture_output=True, text=True)


def prepare_git_branch(repo_root: Path, allow_dirty: bool) -> str | None:
    check = git(repo_root, "rev-parse", "--is-inside-work-tree")
    if check.returncode != 0:
        print("[fixer] not a git repository -- editing files in place with no automatic branch/backup.")
        return None

    status = git(repo_root, "status", "--porcelain")
    if status.stdout.strip() and not allow_dirty:
        print("[fixer] repo has uncommitted changes. Refusing to start (pass --allow-dirty to override).")
        print(status.stdout)
        sys.exit(1)

    branch_name = f"agent-fix/{datetime.now().strftime('%Y%m%d-%H%M%S')}"
    result = git(repo_root, "checkout", "-b", branch_name)
    if result.returncode != 0:
        print(f"[fixer] could not create branch {branch_name}: {result.stderr}")
        sys.exit(1)
    print(f"[fixer] created and checked out branch '{branch_name}' -- review with `git diff` before merging.")
    return branch_name


# --------------------------------------------------------------------------
# Agent loop
# --------------------------------------------------------------------------

SYSTEM_PROMPT = """You are a focused test-fixing agent. You will be given a failing test's \
output from a real repository. Your only goal is to make the test pass by editing the \
minimum necessary source or test code -- do not refactor, add features, or touch unrelated files.

Rules:
- Call record_plan once before your first edit describing your approach and how you'll verify it.
- Read a file with read_file before editing it -- edit_file requires an exact text match.
- After making changes, call run_tests to verify. exit_code 0 means you are done.
- If run_tests still fails, read the new output carefully, adjust, and try again.
- Make the smallest change that fixes the actual bug. Do not modify the test to force it to \
pass unless the test itself is provably wrong (e.g. asserts the wrong expected value for a \
spec that changed) -- prefer fixing the implementation.
- If you determine the task is impossible or blocked (e.g. missing dependency you cannot \
install), say so clearly in a text response instead of calling more tools.
"""


@dataclass
class Outcome:
    status: str
    state: RunState
    final_message: str | None = None


def run_agent(
    client: anthropic.Anthropic,
    model: str,
    repo_root: Path,
    test_cmd: str,
    initial_test_result: dict,
    budget: Budget,
    executor: ToolExecutor,
) -> Outcome:
    state = RunState()
    messages = [
        {
            "role": "user",
            "content": (
                f"The test command is:\n\n    {test_cmd}\n\n"
                f"Running it now gives:\n\nexit_code: {initial_test_result['exit_code']}\n"
                f"stdout:\n{initial_test_result['stdout']}\n\nstderr:\n{initial_test_result['stderr']}\n\n"
                "Investigate the repository and fix the code so this test passes."
            ),
        }
    ]

    while True:
        stop = check_budget(state, budget)
        if stop:
            return Outcome(status=stop, state=state)

        try:
            response = client.messages.create(
                model=model,
                max_tokens=8000,
                system=SYSTEM_PROMPT,
                tools=TOOLS,
                messages=messages,
            )
        except anthropic.AuthenticationError:
            msg = "invalid or missing Anthropic credentials"
            print(f"[fixer] {msg}. Set ANTHROPIC_API_KEY (or ANTHROPIC_AUTH_TOKEN), or run `ant auth login`.")
            return Outcome(status="auth_error", state=state, final_message=msg)
        except anthropic.RateLimitError as e:
            print(f"[fixer] rate limited: {e}")
            return Outcome(status="rate_limited", state=state, final_message=str(e))
        except anthropic.APIStatusError as e:
            print(f"[fixer] API error: {e}")
            return Outcome(status="api_error", state=state, final_message=str(e))
        except TypeError as e:
            # The SDK raises TypeError (not AuthenticationError) when it cannot
            # resolve any credential source at all before a request is even sent.
            if "authentication" in str(e).lower():
                print(f"[fixer] no Anthropic credentials found. Set ANTHROPIC_API_KEY (or "
                      f"ANTHROPIC_AUTH_TOKEN), or run `ant auth login`, then try again.")
                return Outcome(status="auth_error", state=state, final_message=str(e))
            raise

        state.iterations += 1
        state.cost_usd += price(model, response.usage)
        print(f"[fixer] iteration {state.iterations} | cost so far: ${state.cost_usd:.4f} | stop_reason={response.stop_reason}")

        messages.append({"role": "assistant", "content": response.content})

        for block in response.content:
            if block.type == "text" and block.text.strip():
                print(f"[fixer:model] {block.text.strip()}")
            if block.type == "tool_use" and block.name == "record_plan":
                state.plan_revisions += 1
                print(f"[fixer:plan] steps={block.input.get('steps')} success_criteria={block.input.get('success_criteria')!r}")

        if response.stop_reason == "refusal":
            return Outcome(status="refusal", state=state, final_message="model refused the request")

        if response.stop_reason != "tool_use":
            final_text = next((b.text for b in response.content if b.type == "text"), None)
            return Outcome(status="stopped_without_tool_call", state=state, final_message=final_text)

        tool_use_blocks = [b for b in response.content if b.type == "tool_use"]
        tool_results = []
        test_passed = False

        for tc in tool_use_blocks:
            sig = (tc.name, json.dumps(tc.input, sort_keys=True))
            state.call_signatures[sig] += 1
            count = state.call_signatures[sig]

            if count == 2:
                result_payload = {
                    "error": (
                        "You already called this tool with these exact arguments and got this "
                        "same result. Try different arguments, use a different tool, or explain "
                        "what you have found so far in text."
                    )
                }
            else:
                result_payload = executor.dispatch(tc.name, dict(tc.input))
                if tc.name == "run_tests" and result_payload.get("exit_code") == 0:
                    test_passed = True

            state.tool_call_log.append({
                "iteration": state.iterations,
                "name": tc.name,
                "input": tc.input,
                "ok": "error" not in result_payload,
                "result_chars": len(json.dumps(result_payload)),
            })

            tool_results.append({
                "type": "tool_result",
                "tool_use_id": tc.id,
                "content": json.dumps(result_payload),
                "is_error": "error" in result_payload,
            })

        messages.append({"role": "user", "content": tool_results})

        if test_passed:
            return Outcome(status="success", state=state)


# --------------------------------------------------------------------------
# CLI
# --------------------------------------------------------------------------

def main():
    parser = argparse.ArgumentParser(description="Agent that fixes a failing test in a repo.")
    parser.add_argument("--repo", required=True, help="Path to the repository.")
    parser.add_argument("--test-cmd", required=True, help="Command that runs the failing test, e.g. 'pytest tests/test_foo.py::test_bar -q'.")
    parser.add_argument("--model", default="claude-opus-5")
    parser.add_argument("--max-iterations", type=int, default=15)
    parser.add_argument("--max-cost", type=float, default=2.00)
    parser.add_argument("--max-wall-clock", type=float, default=600.0)
    parser.add_argument("--test-timeout", type=float, default=120.0)
    parser.add_argument("--allow-dirty", action="store_true", help="Proceed even if the git working tree has uncommitted changes.")
    parser.add_argument("--no-branch", action="store_true", help="Don't create a new git branch before editing.")
    parser.add_argument("--log-file", default=None)
    args = parser.parse_args()

    repo_root = Path(args.repo).resolve()
    if not repo_root.is_dir():
        print(f"[fixer] repo path does not exist: {repo_root}")
        sys.exit(1)

    client = anthropic.Anthropic()

    if not args.no_branch:
        prepare_git_branch(repo_root, args.allow_dirty)

    executor = ToolExecutor(repo_root, args.test_cmd, args.test_timeout)

    print(f"[fixer] running baseline: {args.test_cmd}")
    baseline = executor.run_tests()
    if "error" in baseline:
        print(f"[fixer] could not run the test command: {baseline['error']}")
        sys.exit(1)
    if baseline["exit_code"] == 0:
        print("[fixer] test already passes -- nothing to do.")
        sys.exit(0)
    print(f"[fixer] confirmed failing (exit_code={baseline['exit_code']}). Starting agent.")
    budget = Budget(
        max_iterations=args.max_iterations,
        max_cost_usd=args.max_cost,
        max_wall_clock_s=args.max_wall_clock,
    )

    outcome = run_agent(
        client=client,
        model=args.model,
        repo_root=repo_root,
        test_cmd=args.test_cmd,
        initial_test_result=baseline,
        budget=budget,
        executor=executor,
    )

    print(f"\n[fixer] finished: status={outcome.status} iterations={outcome.state.iterations} "
          f"cost=${outcome.state.cost_usd:.4f} elapsed={outcome.state.elapsed():.1f}s")
    if outcome.final_message:
        print(f"[fixer] final message: {outcome.final_message}")

    log_path = Path(args.log_file) if args.log_file else repo_root / f"fixer_run_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
    log_path.write_text(json.dumps({
        "status": outcome.status,
        "test_cmd": args.test_cmd,
        "model": args.model,
        "iterations": outcome.state.iterations,
        "cost_usd": outcome.state.cost_usd,
        "elapsed_s": outcome.state.elapsed(),
        "plan_revisions": outcome.state.plan_revisions,
        "tool_calls": outcome.state.tool_call_log,
        "final_message": outcome.final_message,
    }, indent=2))
    print(f"[fixer] run log written to {log_path}")

    sys.exit(0 if outcome.status == "success" else 2)


if __name__ == "__main__":
    main()

# test_fixer_agent

A small agent that takes a failing test in a repo and tries to get it passing.

Point it at any repo and the exact command that runs the failing test. It will:

1. Run that command once to confirm the test is actually failing (the baseline).
2. If the repo is a git repo, refuse to start on a dirty working tree (unless
   `--allow-dirty`), then create and check out a new branch so the agent's
   edits are isolated and reviewable with `git diff` / `git checkout master`.
3. Loop: read files, make a minimal edit, rerun the test command, look at the
   real output, repeat — until the test passes or a budget is hit.
4. Write a JSON run log (iterations, cost, tool calls, final status) next to
   the repo.

It never claims success on its own say-so — the only way the loop ends in
`status: success` is an actual `run_tests` call reporting exit code 0.

```bash
pip install -r requirements.txt
# credentials: ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN env var, or `ant auth login`
```

```bash

```

| `--max-wall-clock` | 600 | Hard cap on run time (seconds) |

## Design notes

- **Manual agent loop**, not the SDK's beta tool runner — iteration/cost/
  wall-clock caps and stuck-loop detection (same tool + same arguments called
  twice in a row) are enforced explicitly in code, per the project's
  agent-loop guidelines, rather than left implicit.
- **Ground truth every step**: the only tool that can end the loop
  successfully is `run_tests`, which shells out to the real test command.
  Nothing is inferred from the model's own text.
- **Tool surface is intentionally narrow**: `list_files`, `read_file`,
  `edit_file` (exact string replace, mirrors Claude Code's Edit tool so the
  model can't corrupt a file with a fuzzy match), `create_file`, `run_tests`,
  `record_plan`. No shell/bash tool, no delete — the safest version of a
  dangerous capability is not having it.
- **Path containment**: every file tool resolves paths relative to the repo
  root and rejects absolute paths or `..` traversal outside it.
- **Sandboxed via git branch**, not a full container — cheap and reversible
  for a local CLI tool, but if you point this at something you can't afford
  to have edited on disk, run it against a disposable clone instead.
