Everything imports and runs cleanly. Here's what I built and the assumptions behind it.

## Assumption (no spec was provided)

You didn't share the actual API — so I assumed a standard CRM shape: **Contacts, Companies, Deals, Activities**, with the usual list/get/create/update/delete verbs, totaling 14 endpoints (`crm_client.py` docstring lists the exact paths). If your real API differs, tell me the actual endpoints/fields and I'll adjust the client layer — the tool layer above it won't need to change much.

## What I built

- **`crm_client.py`** — thin `requests`-based wrapper, one function per REST endpoint (14), auth via `CRM_API_KEY`/`CRM_API_BASE_URL` env vars, errors turned into `CRMAPIError` with actionable messages (rate limit, 404, timeout, validation).
- **`crm_tools.py`** — the agent-facing layer, **13 tools** consolidated from the 14 endpoints per the tool-design skill:
  - `get_contact_details` / `get_company_details` each fold in 2-3 REST calls (profile + open deals + recent activity) into one tool call, instead of making the agent chain lookups.
  - Every search tool takes typed fields (no query DSL), has a `response_format: concise|detailed` enum to cut token cost, and caps `limit` at 50.
  - `delete_contact` is a separate, explicitly-named tool requiring `confirm=True` — kept apart from `update_contact` rather than a status flag, since silently-wrong deletes are the worst failure mode.
  - `stage` (deals) and `type` (activities) stay as enum parameters, not decomposed into per-value tools, since they're ordinary categorical values, not polarity/destructive flags.
  - `create_contact`, `create_deal`, and `log_activity` carry `input_examples` (minimal + full patterns) since their schemas have optional fields whose conventions (ID formats, which fields co-occur) aren't obvious from types alone.
  - Every error return is a steering message (e.g. "Invalid stage 'x'. Must be one of: ...") rather than a raw exception.
- **`agent.py`** — a plain while-loop agent (Anthropic Messages API, `claude-sonnet-5`, direct SDK calls, no framework) wiring `TOOLS`/`DISPATCH` together.
- **`requirements.txt`**, **`.env.example`**.

I verified the tool schemas are valid/JSON-serializable, schema names match the dispatch table, and the validation/error paths (missing confirm, bad stage, missing associations, missing API key) all return clean error dicts instead of throwing.

## Not done, worth knowing

At 13 tools I skipped `defer_loading`/tool-search (the skill's threshold is ~10+ tools *with* selection problems — you're right at the edge, so I left it out; easy to add later if you see wrong-tool picks). I also didn't build an eval harness (`evals-before-shipping` skill) to actually measure tool-selection/argument accuracy — recommend doing that against your real API before production use, since several of my consolidation choices (e.g. what counts as "recent" activity, the confirm-gate on delete) are judgment calls that should be validated against real usage.

### `agent.py`

````py
"""
Minimal agent loop exposing the CRM tools (crm_tools.TOOLS / DISPATCH) to Claude.

Usage:
    export ANTHROPIC_API_KEY=...
    export CRM_API_BASE_URL=https://api.yourcrm.com/v1
    export CRM_API_KEY=...
    python agent.py
"""
from __future__ import annotations

import json
import os

import anthropic

from crm_tools import DISPATCH, TOOLS

MODEL = os.environ.get("ANTHROPIC_MODEL", "claude-sonnet-5")

SYSTEM_PROMPT = (
    "You are a CRM assistant. Use the available tools to look up and modify "
    "contacts, companies, deals, and activities. Prefer the *_details tools "
    "when the user asks about a specific person or account rather than "
    "chaining multiple searches. Never call delete_contact with confirm=True "
    "unless the user has explicitly asked to delete that contact."
)


def run_tool(name: str, tool_input: dict) -> dict:
    fn = DISPATCH.get(name)
    if fn is None:
        return {"error": f"Unknown tool '{name}'."}
    try:
        return fn(**tool_input)
    except TypeError as e:
        return {"error": f"Bad arguments for {name}: {e}"}


def run_agent_loop(client: anthropic.Anthropic, user_message: str, max_turns: int = 8) -> str:
    messages = [{"role": "user", "content": user_message}]

    for _ in range(max_turns):
        response = client.messages.create(
            model=MODEL,
            max_tokens=2048,
            system=SYSTEM_PROMPT,
            tools=TOOLS,
            messages=messages,
        )

        if response.stop_reason != "tool_use":
            return "".join(block.text for block in response.content if block.type == "text")

        messages.append({"role": "assistant", "content": response.content})

        tool_results = []
        for block in response.content:
            if block.type != "tool_use":
                continue
            result = run_tool(block.name, block.input)
            tool_results.append(
                {
                    "type": "tool_result",
                    "tool_use_id": block.id,
                    "content": json.dumps(result),
                }
            )
        messages.append({"role": "user", "content": tool_results})

    return "Reached max turns without a final answer."


def main() -> None:
    client = anthropic.Anthropic()
    print("CRM agent ready. Type a request (Ctrl+C to exit).")
    while True:
        try:
            user_message = input("\n> ")
        except (EOFError, KeyboardInterrupt):
            break
        if not user_message.strip():
            continue
        print(run_agent_loop(client, user_message))


if __name__ == "__main__":
    main()

````

"""
Thin HTTP client for the CRM's 14 REST endpoints.

Assumed API shape (adjust base paths/fields to match your actual CRM):
  Contacts:   GET /contacts, GET /contacts/{id}, POST /contacts,
              PATCH /contacts/{id}, DELETE /contacts/{id}
  Companies:  GET /companies, GET /companies/{id}, POST /companies
  Deals:      GET /deals, GET /deals/{id}, POST /deals, PATCH /deals/{id}
  Activities: GET /activities, POST /activities

Auth: Bearer token. Config via env vars CRM_API_BASE_URL / CRM_API_KEY.

from __future__ import annotations

import os
from typing import Any

import requests

CRM_API_BASE_URL = os.environ.get("CRM_API_BASE_URL", "https://api.example-crm.com/v1")
CRM_API_KEY = os.environ.get("CRM_API_KEY")

_TIMEOUT = 10


class CRMAPIError(Exception):
    """Raised on non-2xx responses. Message is written to be shown to the agent."""


def _request(method: str, path: str, *, params: dict | None = None, json: dict | None = None) -> dict:
    if not CRM_API_KEY:
        raise CRMAPIError("CRM_API_KEY is not configured. Set it in the environment before retrying.")

    url = f"{CRM_API_BASE_URL}{path}"
    headers = {"Authorization": f"Bearer {CRM_API_KEY}", "Content-Type": "application/json"}
    try:
        resp = requests.request(method, url, headers=headers, params=params, json=json, timeout=_TIMEOUT)
    except requests.exceptions.Timeout:
        raise CRMAPIError(f"CRM API timed out after {_TIMEOUT}s calling {method} {path}. Retry once; if it times out again, narrow the request (smaller limit or date range).")
    except requests.exceptions.ConnectionError as e:
        raise CRMAPIError(f"Could not reach the CRM API at {CRM_API_BASE_URL}: {e}")

    if resp.status_code == 404:
        raise CRMAPIError(f"No record found for {method} {path}. Verify the id is correct, e.g. by searching first.")
    if resp.status_code == 429:
        raise CRMAPIError("CRM API rate limit hit. Wait a moment and retry with fewer/narrower calls.")
    if resp.status_code == 422:
        raise CRMAPIError(f"CRM API rejected the request body as invalid: {resp.text[:500]}. Check required fields and formats.")
    if not resp.ok:
        raise CRMAPIError(f"CRM API error {resp.status_code} on {method} {path}: {resp.text[:500]}")

    if resp.status_code == 204 or not resp.content:
        return {}
    return resp.json()

### `crm_tools.py`

"""
Agent-facing tools over the CRM REST API.

Design notes (see the tool-design skill for the full rationale):
- 14 REST endpoints are consolidated into fewer, task-shaped tools. Fetching
  "everything about a contact/company" is one tool call instead of three.
- Every list/search tool takes typed fields, never a query-string DSL.
- Every list/search tool has a `response_format` (concise/detailed) so the
  agent isn't paying for fields it doesn't need.
- Every list tool caps `limit` and paginates via `cursor` rather than
  returning unbounded results.
- Errors are steering messages: they say what to change, not a traceback.
- `delete_contact` requires an explicit `confirm=True` since it's the only
  destructive tool in the set and a wrong call can't be undone.
"""
from __future__ import annotations

from typing import Any

import crm_client as api
from crm_client import CRMAPIError

MAX_LIST_LIMIT = 50


def _clamp_limit(limit: int) -> int:
    return max(1, min(limit, MAX_LIST_LIMIT))


def _shape_contact(c: dict, detailed: bool) -> dict:
    out = {
        "id": c.get("id"),
        "name": c.get("name") or f"{c.get('first_name', '')} {c.get('last_name', '')}".strip(),
        "email": c.get("email"),
        "company_name": c.get("company_name"),
    }
    if detailed:
        out.update(
            phone=c.get("phone"),
            title=c.get("title"),
            owner=c.get("owner"),
            created_at=c.get("created_at"),
            notes=c.get("notes"),
        )
    return out


def _shape_company(c: dict, detailed: bool) -> dict:
    out = {"id": c.get("id"), "name": c.get("name"), "domain": c.get("domain")}
    if detailed:
        out.update(
            industry=c.get("industry"),
            size=c.get("size"),
            owner=c.get("owner"),
            created_at=c.get("created_at"),
        )
    return out


def _shape_deal(d: dict, detailed: bool) -> dict:
    out = {
        "id": d.get("id"),
        "title": d.get("title"),
        "stage": d.get("stage"),
        "value": d.get("value"),
        "currency": d.get("currency", "USD"),
    }
    if detailed:
        out.update(
            contact_id=d.get("contact_id"),
            company_id=d.get("company_id"),
            expected_close_date=d.get("expected_close_date"),
            owner=d.get("owner"),
            created_at=d.get("created_at"),
        )
    return out


def _shape_activity(a: dict) -> dict:
    return {
        "id": a.get("id"),
        "type": a.get("type"),
        "subject": a.get("subject"),
        "created_at": a.get("created_at"),
        "contact_id": a.get("contact_id"),
        "deal_id": a.get("deal_id"),
    }

# Tools

def search_contacts(query: str, limit: int = 10, response_format: str = "concise") -> dict:
    limit = _clamp_limit(limit)
    try:
        result = api.list_contacts(query=query, limit=limit)
    except CRMAPIError as e:
        return {"error": str(e)}
    contacts = [_shape_contact(c, response_format == "detailed") for c in result.get("results", [])]
    return {"contacts": contacts, "next_cursor": result.get("next_cursor")}


def get_contact_details(contact_id: str) -> dict:
    """Contact profile + its open deals + 5 most recent activities, in one call."""
    try:
        contact = api.get_contact(contact_id)
        deals = api.list_deals(contact_id=contact_id, limit=10).get("results", [])
        activities = api.list_activities(contact_id=contact_id, limit=5).get("results", [])
    except CRMAPIError as e:
        return {"error": str(e)}
    return {
        "contact": _shape_contact(contact, detailed=True),
        "open_deals": [_shape_deal(d, detailed=False) for d in deals if d.get("stage") not in ("closed_won", "closed_lost")],
        "recent_activity": [_shape_activity(a) for a in activities],
    }


def create_contact(
    first_name: str,
    last_name: str,
    email: str,
    phone: str | None = None,
    company_name: str | None = None,
    title: str | None = None,
) -> dict:
    payload = {"first_name": first_name, "last_name": last_name, "email": email}
    if phone:
        payload["phone"] = phone
    if company_name:
        payload["company_name"] = company_name
    if title:
        payload["title"] = title
    try:
        created = api.create_contact(payload)
    except CRMAPIError as e:
        return {"error": str(e)}
    return {"contact": _shape_contact(created, detailed=True)}
