**Built at `sales-summary/`** — a workflow script, not an autonomous agent, since reading a CSV, computing stats, and emailing is a fixed 3-step process every time (no unpredictable step count, no need for the model to decide what to do next).

What's there:
- `sales_summary.py` — parses the CSV (flexible column detection, computes amount from quantity×price if no amount column), builds a summary with day-over-day comparison and top products/reps/regions, sends via SMTP.
- `.env.example` — all config (CSV path, recipients, SMTP creds) via env vars, nothing hardcoded.
- `sample_data/sales.csv` + `test_sales_summary.py` — 5 tests, all passing.
- `README.md` — setup, CSV schema, and Windows Task Scheduler / cron snippets for the "every morning" part.

Verified: unit tests pass, and I confirmed the SMTP send path correctly raises and reports a clean error (tested against a local debug SMTP server — real delivery needs your actual SMTP credentials, which I obviously can't fabricate).

### `sales-summary/README.md`

````md
# Daily Sales Summary

Reads the daily sales CSV, computes a summary (revenue, units, orders, top
products/reps/regions, day-over-day change), and emails it to the team.

This is a plain workflow script (no LLM, no autonomous loop) — the steps are
fixed and deterministic, so that's the simplest thing that reliably works.

## Setup

1. `pip install pytest` (only needed to run the tests; the script itself uses
   only the Python standard library).
2. Copy `.env.example` to `.env` and fill in your CSV path, recipients, and
   SMTP credentials. Gmail/Office365 require an app password, not your login
   password.
3. Load `.env` into the environment before running (PowerShell):
   ```powershell
   Get-Content .env | ForEach-Object {
       if ($_ -match '^\s*([^#][^=]*)=(.*)$') {
           [System.Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim())
       }
   }
   ```
4. Run it:
   ```powershell
   python sales_summary.py
   ```
   By default it summarizes the most recent date found in the CSV. Pass an
   explicit date to summarize a specific day:
   ```powershell
   python sales_summary.py 2026-09-15
   ```

## CSV format

Required columns (case-insensitive): `date` (YYYY-MM-DD), `order_id`,
`product`. Also required: either an `amount` column, or both `quantity` and
`unit_price` (amount is computed as quantity × unit_price). Optional:
`rep`, `region` — enable the top-reps/top-regions breakdown when present.

See `sample_data/sales.csv` for an example.

## Scheduling it every morning (Windows Task Scheduler)

```powershell
$action = New-ScheduledTaskAction -Execute "python.exe" `
    -Argument "C:\tmp\skills-eval\arm-b\t13-r1\sales-summary\sales_summary.py" `
    -WorkingDirectory "C:\tmp\skills-eval\arm-b\t13-r1\sales-summary"
$trigger = New-ScheduledTaskTrigger -Daily -At 7:00am
Register-ScheduledTask -TaskName "DailySalesSummary" -Action $action -Trigger $trigger `
    -Description "Emails the team a daily sales summary"
```

Task Scheduler runs with its own environment, so either set the
`SALES_SUMMARY_*` variables as system/user environment variables (not just in
a local `.env` file the shell loaded interactively), or point
`-Argument` at a small `.bat`/`.ps1` wrapper that loads `.env` first and then
calls `sales_summary.py`.

On Linux/macOS, use cron instead:
```
0 7 * * * cd /path/to/sales-summary && /usr/bin/env python3 sales_summary.py >> run.log 2>&1
```
````

### `sales-summary/sales_summary.py`

````py
"""
Daily sales summary emailer.

Reads a daily sales CSV, computes a summary, and emails it to the team.
Intended to be run once per day by a scheduler (Windows Task Scheduler / cron).

Expected CSV columns (case-insensitive, order doesn't matter):
    date        - order date, e.g. 2026-09-15
    order_id    - unique order identifier
    product     - product name
    quantity    - units sold (int)
    unit_price  - price per unit (float)
    amount      - optional; if absent, computed as quantity * unit_price
    rep         - optional; sales rep name, for a "top rep" breakdown
    region      - optional; region name, for a "top region" breakdown

All configuration comes from environment variables so no secrets live in
source control. See .env.example for the full list.
"""
from __future__ import annotations

import csv
import os
import smtplib
import sys
from collections import defaultdict
from dataclasses import dataclass, field
from datetime import date, datetime, timedelta
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from pathlib import Path


class ConfigError(RuntimeError):
    pass


@dataclass
class Config:
    csv_path: Path
    smtp_host: str
    smtp_port: int
    smtp_user: str
    smtp_password: str
    sender: str
    recipients: list[str]
    use_tls: bool = True
    history_dir: Path | None = None

    @classmethod
    def from_env(cls) -> "Config":
        def require(name: str) -> str:
            value = os.environ.get(name, "").strip()
            if not value:
                raise ConfigError(f"Missing required environment variable: {name}")
            return value

        recipients_raw = require("SALES_SUMMARY_RECIPIENTS")
        recipients = [r.strip() for r in recipients_raw.split(",") if r.strip()]
        if not recipients:
            raise ConfigError("SALES_SUMMARY_RECIPIENTS resolved to an empty list")

        history_dir_raw = os.environ.get("SALES_SUMMARY_HISTORY_DIR", "").strip()

        return cls(
            csv_path=Path(require("SALES_SUMMARY_CSV_PATH")),
            smtp_host=require("SALES_SUMMARY_SMTP_HOST"),
            smtp_port=int(os.environ.get("SALES_SUMMARY_SMTP_PORT", "587")),
            smtp_user=require("SALES_SUMMARY_SMTP_USER"),
            smtp_password=require("SALES_SUMMARY_SMTP_PASSWORD"),
            sender=os.environ.get("SALES_SUMMARY_SENDER", "").strip() or require("SALES_SUMMARY_SMTP_USER"),
            recipients=recipients,
            use_tls=os.environ.get("SALES_SUMMARY_SMTP_TLS", "true").strip().lower() not in ("0", "false", "no"),
            history_dir=Path(history_dir_raw) if history_dir_raw else None,
        )


@dataclass
class SalesRow:
    order_id: str
    order_date: date
    product: str
    quantity: float
    amount: float
    rep: str | None = None
    region: str | None = None


@dataclass
class Summary:
    report_date: date
    row_count: int
    total_revenue: float
    total_units: float
    unique_orders: int
    top_products: list[tuple[str, float]] = field(default_factory=list)
    top_reps: list[tuple[str, float]] = field(default_factory=list)
    top_regions: list[tuple[str, float]] = field(default_factory=list)
    prior_day_revenue: float | None = None


def _normalize_header(name: str) -> str:
    return name.strip().lower().replace(" ", "_")


def load_rows(csv_path: Path) -> list[SalesRow]:
    if not csv_path.exists():
        raise ConfigError(f"CSV file not found: {csv_path}")

    with csv_path.open(newline="", encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        if reader.fieldnames is None:
            raise ConfigError(f"CSV file has no header row: {csv_path}")
        field_map = {_normalize_header(name): name for name in reader.fieldnames}

        for required in ("date", "order_id", "product"):
            if required not in field_map:
                raise ConfigError(f"CSV is missing required column '{required}'")

        has_amount = "amount" in field_map
        has_price = "unit_price" in field_map and "quantity" in field_map
        if not has_amount and not has_price:
            raise ConfigError(
                "CSV must have either an 'amount' column or both 'quantity' and 'unit_price' columns"
            )

        rows: list[SalesRow] = []
        for i, raw in enumerate(reader, start=2):  # header is line 1
            try:
                order_date = datetime.strptime(raw[field_map["date"]].strip(), "%Y-%m-%d").date()
                quantity = float(raw[field_map["quantity"]]) if "quantity" in field_map else 0.0
                if has_amount:
                    amount = float(raw[field_map["amount"]])
                else:
                    amount = quantity * float(raw[field_map["unit_price"]])
                rows.append(
                    SalesRow(
                        order_id=raw[field_map["order_id"]].strip(),
                        order_date=order_date,
                        product=raw[field_map["product"]].strip(),
                        quantity=quantity,
                        amount=amount,
                        rep=raw[field_map["rep"]].strip() if "rep" in field_map else None,
                        region=raw[field_map["region"]].strip() if "region" in field_map else None,
                    )
                )
            except (KeyError, ValueError) as exc:
                raise ConfigError(f"Bad data on CSV line {i}: {exc}") from exc

    return rows


def _top_n(totals: dict[str, float], n: int = 3) -> list[tuple[str, float]]:
    return sorted(totals.items(), key=lambda kv: kv[1], reverse=True)[:n]


def build_summary(rows: list[SalesRow], report_date: date, prior_day_revenue: float | None) -> Summary:
    day_rows = [r for r in rows if r.order_date == report_date]
    if not day_rows:
        raise ConfigError(f"No rows found for {report_date.isoformat()} in the CSV")

    product_totals: dict[str, float] = defaultdict(float)
    rep_totals: dict[str, float] = defaultdict(float)
    region_totals: dict[str, float] = defaultdict(float)

    for r in day_rows:
        product_totals[r.product] += r.amount
        if r.rep:
            rep_totals[r.rep] += r.amount
        if r.region:
            region_totals[r.region] += r.amount

    return Summary(
        report_date=report_date,
        row_count=len(day_rows),
        total_revenue=sum(r.amount for r in day_rows),
        total_units=sum(r.quantity for r in day_rows),
        unique_orders=len({r.order_id for r in day_rows}),
        top_products=_top_n(product_totals),
        top_reps=_top_n(rep_totals),
        top_regions=_top_n(region_totals),
        prior_day_revenue=prior_day_revenue,
    )


def render_email(summary: Summary) -> tuple[str, str]:
    subject = f"Daily Sales Summary — {summary.report_date.isoformat()}"

    lines = [
        f"Sales summary for {summary.report_date.isoformat()}",
        "",
        f"Total revenue:   ${summary.total_revenue:,.2f}",
        f"Units sold:      {summary.total_units:,.0f}",
        f"Orders:          {summary.unique_orders}",
    ]

    if summary.prior_day_revenue is not None:
        delta = summary.total_revenue - summary.prior_day_revenue
        pct = (delta / summary.prior_day_revenue * 100) if summary.prior_day_revenue else 0.0
        arrow = "up" if delta >= 0 else "down"
        lines.append(f"vs. prior day:   {arrow} ${abs(delta):,.2f} ({pct:+.1f}%)")

    if summary.top_products:
        lines.append("")
        lines.append("Top products:")
        for name, total in summary.top_products:
            lines.append(f"  - {name}: ${total:,.2f}")

    if summary.top_reps:
        lines.append("")
        lines.append("Top reps:")
        for name, total in summary.top_reps:
            lines.append(f"  - {name}: ${total:,.2f}")

    if summary.top_regions:
        lines.append("")
        lines.append("Top regions:")
        for name, total in summary.top_regions:
            lines.append(f"  - {name}: ${total:,.2f}")

    return subject, "\n".join(lines)


def send_email(config: Config, subject: str, body: str) -> None:
    msg = MIMEMultipart()
    msg["From"] = config.sender
    msg["To"] = ", ".join(config.recipients)
    msg["Subject"] = subject
    msg.attach(MIMEText(body, "plain"))

    with smtplib.SMTP(config.smtp_host, config.smtp_port, timeout=30) as server:
        if config.use_tls:
            server.starttls()
        server.login(config.smtp_user, config.smtp_password)
        server.sendmail(config.sender, config.recipients, msg.as_string())


def _prior_day_revenue(rows: list[SalesRow], report_date: date) -> float | None:
    prior = report_date - timedelta(days=1)
    prior_rows = [r for r in rows if r.order_date == prior]
    if not prior_rows:
        return None
    return sum(r.amount for r in prior_rows)


def run(report_date: date | None = None) -> None:
    config = Config.from_env()
    rows = load_rows(config.csv_path)
    target_date = report_date or max(r.order_date for r in rows)

    summary = build_summary(rows, target_date, _prior_day_revenue(rows, target_date))
    subject, body = render_email(summary)
    send_email(config, subject, body)
    print(f"Sent summary for {target_date.isoformat()} to {', '.join(config.recipients)}")


def main() -> int:
    report_date = None
    if len(sys.argv) > 1:
        try:
            report_date = datetime.strptime(sys.argv[1], "%Y-%m-%d").date()
        except ValueError:
            print(f"Invalid date argument '{sys.argv[1]}', expected YYYY-MM-DD", file=sys.stderr)
            return 2

    try:
        run(report_date)
    except ConfigError as exc:
        print(f"Error: {exc}", file=sys.stderr)
        return 1
    except smtplib.SMTPException as exc:
        print(f"Error sending email: {exc}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
````

### `sales-summary/test_sales_summary.py`

````py
from datetime import date
from pathlib import Path

import pytest

from sales_summary import build_summary, load_rows, render_email, ConfigError

SAMPLE_CSV = Path(__file__).parent / "sample_data" / "sales.csv"


def test_load_rows_parses_sample_csv():
    rows = load_rows(SAMPLE_CSV)
    assert len(rows) == 7
    assert rows[0].product == "Widget A"
    assert rows[0].amount == pytest.approx(5 * 19.99)


def test_build_summary_totals_and_top_products():
    rows = load_rows(SAMPLE_CSV)
    summary = build_summary(rows, date(2026, 9, 15), prior_day_revenue=None)

    assert summary.row_count == 4
    assert summary.unique_orders == 4
    expected_total = 3 * 19.99 + 10 * 9.99 + 1 * 49.99 + 4 * 9.99
    assert summary.total_revenue == pytest.approx(expected_total)
    assert summary.top_products[0][0] == "Widget C"  # 10*9.99 + 4*9.99 = 139.86, highest


def test_build_summary_raises_for_missing_date():
    rows = load_rows(SAMPLE_CSV)
    with pytest.raises(ConfigError):
        build_summary(rows, date(2099, 1, 1), prior_day_revenue=None)


def test_render_email_includes_delta_when_prior_day_given():
    rows = load_rows(SAMPLE_CSV)
    summary = build_summary(rows, date(2026, 9, 15), prior_day_revenue=100.0)
    subject, body = render_email(summary)

    assert "2026-09-15" in subject
    assert "vs. prior day" in body
    assert "Top products" in body


def test_load_rows_missing_file_raises_config_error(tmp_path):
    with pytest.raises(ConfigError):
        load_rows(tmp_path / "does_not_exist.csv")
````
