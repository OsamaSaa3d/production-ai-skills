## What I built

**`parse_invoices.py`** — stdlib-only script that:
- Reads `.txt` invoices from `invoices/` (configurable via `--input-dir`)
- Extracts invoice number, issue date, total, customer name, PO number via regex, tolerant of common label wording variations
- Normalizes dates to `YYYY-MM-DD` and totals to floats
- Upserts into an `orders` table in SQLite (`orders.db` by default, keyed on invoice number so re-runs don't duplicate)
- Skips and reports (not silently writes) any invoice missing a required field
- Optional `--csv` export and `--dry-run` preview

**`invoices/`** — two sample invoices with differently-worded fields, used to exercise the parser.

**`README.md`** — documents the assumptions and schema.

Since your working directory was empty, I had to guess at the storage target — I used SQLite as a zero-dependency stand-in for "our orders table." If you already have a real database, swap the connection logic in `write_to_db()` (the schema/SQL should port as-is), and tell me what invoice format(s) you actually receive so I can tighten the regex patterns instead of guessing at label synonyms.

Caught one bug during testing: the total-amount regex was initially matching "Subtotal" as a substring instead of "Total Due" — fixed with a word-boundary check and re-verified against both samples.

### `parse_invoices.py`

````py
#!/usr/bin/env python3
"""
parse_invoices.py

Reads plain-text invoices from a folder, extracts:
  - invoice number
  - issue date
  - total
  - customer name
  - PO number

...and upserts them into an `orders` table in a SQLite database.

Usage:
    python parse_invoices.py --input-dir invoices --db orders.db
    python parse_invoices.py --input-dir invoices --db orders.db --dry-run
    python parse_invoices.py --input-dir invoices --db orders.db --csv orders_export.csv

Notes:
  - Only the Python standard library is used (sqlite3, re, argparse, csv, datetime),
    so this runs anywhere without extra installs.
  - Label wording in real invoices varies ("Invoice #" vs "Invoice No." vs
    "Invoice Number", etc.) so each field is matched against a few common
    synonyms. If your invoices use different wording, add a pattern to the
    relevant list in FIELD_PATTERNS below.
  - If a required field can't be found in a file, that file is skipped and
    reported at the end instead of writing a partial/garbage row.
"""

import argparse
import csv
import glob
import os
import re
import sqlite3
import sys
from dataclasses import dataclass
from datetime import datetime
from typing import Optional


# ---------------------------------------------------------------------------
# Field extraction
# ---------------------------------------------------------------------------

# Each field has a list of candidate regexes (case-insensitive). The first
# capture group is the value. Patterns are tried in order; first match wins.
FIELD_PATTERNS = {
    "invoice_number": [
        r"invoice\s*(?:number|no\.?|#)\s*[:\-]?\s*(\S+)",
        r"inv\s*(?:number|no\.?|#)\s*[:\-]?\s*(\S+)",
    ],
    "issue_date": [
        r"(?:issue|invoice)\s*date\s*[:\-]?\s*(.+)",
        r"^date\s*[:\-]?\s*(.+)",
    ],
    "total": [
        r"\b(?:grand\s*)?total\s*(?:due)?\s*[:\-]?\s*\$?\s*([\d,]+\.\d{2})",
        r"\bamount\s*due\s*[:\-]?\s*\$?\s*([\d,]+\.\d{2})",
        r"\bbalance\s*due\s*[:\-]?\s*\$?\s*([\d,]+\.\d{2})",
    ],
    "customer_name": [
        r"(?:bill\s*to|customer|client)\s*[:\-]?\s*(.+)",
    ],
    "po_number": [
        r"(?:p\.?\s*o\.?|purchase\s*order)\s*(?:number|no\.?|#)?\s*[:\-]?\s*(\S+)",
    ],
}

DATE_INPUT_FORMATS = [
    "%Y-%m-%d",
    "%m/%d/%Y",
    "%d/%m/%Y",
    "%B %d, %Y",
    "%b %d, %Y",
    "%d %B %Y",
    "%d-%b-%Y",
    "%m-%d-%Y",
]


@dataclass
class ParsedInvoice:
    invoice_number: str
    issue_date: str  # normalized to YYYY-MM-DD when possible, else raw text
    total: float
    customer_name: str
    po_number: Optional[str]
    source_file: str


class ExtractionError(Exception):
    pass


def _find_field(text: str, field: str, required: bool) -> Optional[str]:
    for pattern in FIELD_PATTERNS[field]:
        m = re.search(pattern, text, re.IGNORECASE | re.MULTILINE)
        if m:
            return m.group(1).strip().rstrip(",")
    if required:
        raise ExtractionError(f"could not find '{field}'")
    return None


def _normalize_date(raw: str) -> str:
    raw = raw.strip()
    for fmt in DATE_INPUT_FORMATS:
        try:
            return datetime.strptime(raw, fmt).strftime("%Y-%m-%d")
        except ValueError:
            continue
    # Couldn't confidently parse it -- keep the raw text rather than guessing.
    return raw


def _normalize_total(raw: str) -> float:
    return float(raw.replace(",", ""))


def parse_invoice_text(text: str, source_file: str) -> ParsedInvoice:
    invoice_number = _find_field(text, "invoice_number", required=True)
    issue_date_raw = _find_field(text, "issue_date", required=True)
    total_raw = _find_field(text, "total", required=True)
    customer_name = _find_field(text, "customer_name", required=True)
    po_number = _find_field(text, "po_number", required=False)  # not all orders have one

    return ParsedInvoice(
        invoice_number=invoice_number,
        issue_date=_normalize_date(issue_date_raw),
        total=_normalize_total(total_raw),
        customer_name=customer_name,
        po_number=po_number,
        source_file=source_file,
    )


# ---------------------------------------------------------------------------
# Storage
# ---------------------------------------------------------------------------

SCHEMA = """
CREATE TABLE IF NOT EXISTS orders (
    invoice_number TEXT PRIMARY KEY,
    issue_date     TEXT NOT NULL,
    total          REAL NOT NULL,
    customer_name  TEXT NOT NULL,
    po_number      TEXT,
    source_file    TEXT,
    imported_at    TEXT NOT NULL DEFAULT (datetime('now'))
);
"""

UPSERT = """
INSERT INTO orders (invoice_number, issue_date, total, customer_name, po_number, source_file)
VALUES (:invoice_number, :issue_date, :total, :customer_name, :po_number, :source_file)
ON CONFLICT(invoice_number) DO UPDATE SET
    issue_date=excluded.issue_date,
    total=excluded.total,
    customer_name=excluded.customer_name,
    po_number=excluded.po_number,
    source_file=excluded.source_file,
    imported_at=datetime('now');
"""


def write_to_db(db_path: str, invoices: list[ParsedInvoice]) -> None:
    conn = sqlite3.connect(db_path)
    try:
        conn.execute(SCHEMA)
        conn.executemany(UPSERT, [inv.__dict__ for inv in invoices])
        conn.commit()
    finally:
        conn.close()


def write_to_csv(csv_path: str, invoices: list[ParsedInvoice]) -> None:
    fields = ["invoice_number", "issue_date", "total", "customer_name", "po_number", "source_file"]
    with open(csv_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        for inv in invoices:
            writer.writerow({k: getattr(inv, k) for k in fields})


# ---------------------------------------------------------------------------
# CLI
# ---------------------------------------------------------------------------

def main() -> int:
    parser = argparse.ArgumentParser(description="Extract order fields from plain-text invoices.")
    parser.add_argument("--input-dir", default="invoices", help="Folder of .txt invoices (default: invoices)")
    parser.add_argument("--db", default="orders.db", help="SQLite DB file to write the orders table into")
    parser.add_argument("--csv", default=None, help="Optional path to also export results as CSV")
    parser.add_argument("--dry-run", action="store_true", help="Parse and print results without writing to the DB")
    args = parser.parse_args()

    paths = sorted(glob.glob(os.path.join(args.input_dir, "*.txt")))
    if not paths:
        print(f"No .txt files found in '{args.input_dir}'.", file=sys.stderr)
        return 1

    parsed: list[ParsedInvoice] = []
    failures: list[tuple[str, str]] = []

    for path in paths:
        with open(path, "r", encoding="utf-8") as f:
            text = f.read()
        try:
            parsed.append(parse_invoice_text(text, source_file=os.path.basename(path)))
        except ExtractionError as e:
            failures.append((path, str(e)))

    for inv in parsed:
        print(
            f"{inv.invoice_number} | {inv.issue_date} | {inv.total:.2f} | "
            f"{inv.customer_name} | PO {inv.po_number or '(none)'} | {inv.source_file}"
        )

    if failures:
        print("\nSkipped (missing required field):", file=sys.stderr)
        for path, reason in failures:
            print(f"  {path}: {reason}", file=sys.stderr)

    if args.dry_run:
        print("\nDry run -- nothing written.")
        return 0 if parsed else 1

    if parsed:
        write_to_db(args.db, parsed)
        print(f"\nWrote {len(parsed)} row(s) to {args.db} (table 'orders').")
        if args.csv:
            write_to_csv(args.csv, parsed)
            print(f"Also exported to {args.csv}.")

    return 0 if not failures else 2


if __name__ == "__main__":
    raise SystemExit(main())

````

### `README.md`

````md
# Invoice → Orders extraction

Pulls **invoice number, issue date, total, customer name, and PO number** out
of plain-text invoices and writes them to an `orders` table.

## Assumptions

No existing invoice samples or orders table were available when this was
built, so:

- Invoices are expected as `.txt` files, one invoice per file, in an
  `invoices/` folder (two samples are included).
- Output goes to a local SQLite database (`orders.db`), table `orders`,
  since no real database/connection was specified. Point `--db` at a
  different file, or adapt `write_to_db()` in `parse_invoices.py` to your
  actual DB driver (Postgres/MySQL/etc.) if you already have one — the
  SQL (`SCHEMA` / `UPSERT` constants) is standard enough to port directly.
- Field labels vary by vendor ("Invoice #" vs "Invoice No." vs "Invoice
  Number", "Bill To" vs "Customer", etc.), so each field is matched against
  a few common synonyms rather than one fixed string. If your invoices use
  wording the parser doesn't recognize, add a pattern to `FIELD_PATTERNS`
  in `parse_invoices.py`.
- PO number is treated as optional (not every order has one); the other
  four fields are required — a file missing any of them is skipped and
  reported rather than written with blank/garbage data.
- Re-running against the same files is safe: rows are upserted keyed on
  invoice number, so re-processing doesn't create duplicates.

## Usage

```bash
# Parse everything in invoices/ and write to orders.db
python parse_invoices.py --input-dir invoices --db orders.db

# Preview extraction without writing anything
python parse_invoices.py --input-dir invoices --db orders.db --dry-run

# Also export a CSV alongside the DB write
python parse_invoices.py --input-dir invoices --db orders.db --csv orders_export.csv
```

## Orders table schema

```sql
CREATE TABLE orders (
    invoice_number TEXT PRIMARY KEY,
    issue_date     TEXT NOT NULL,   -- normalized to YYYY-MM-DD when the source format is recognized
    total          REAL NOT NULL,
    customer_name  TEXT NOT NULL,
    po_number      TEXT,            -- nullable
    source_file    TEXT,
    imported_at    TEXT NOT NULL
);
```

## What was verified

- Two sample invoices with different formatting/wording both parse correctly
  end-to-end into `orders.db`.
- Re-running the script against the same files does not duplicate rows.
- An invoice missing a required field is skipped and reported on stderr
  instead of writing incomplete data.
- Caught and fixed a regex bug where "Total Due" was being matched inside
  "Subtotal" (substring match) — patterns now use word boundaries.
````
