**What it does**
- `sales_summary_agent.py` reads the sales CSV with pandas, computes every number itself (total revenue, units, transactions, avg order value, top products/regions, day-over-day % change) — then makes **one** Claude API call (`claude-opus-5`, low effort, since this is just "write a short paragraph") to turn those already-computed numbers into a friendly opening paragraph. Claude never invents or recalculates a figure; it only narrates numbers it's handed, so the report can't drift from the data.
- If `ANTHROPIC_API_KEY` isn't set, or the call fails/gets rate-limited/refuses, it falls back to a plain-template paragraph automatically — the team still gets a complete report every morning either way.
- Sends via SMTP as a combined plain-text + HTML email.

**Verified working**: installed deps in a scratch venv, ran `--dry-run` against `sample_sales.csv` (two days of data), got a correct report — $2,802.40 revenue, +53.8% day-over-day, top product/region breakdown — then deleted the venv so the deliverable stays clean.

````md
# Daily Sales Summary Agent

Reads your daily sales CSV, computes the day's numbers with pandas, asks
Claude for a short friendly narrative on top of those numbers, and emails
the result to the team. Designed to run once a morning via a scheduler.

**Why it's built this way:** every number in the email (revenue, units,
top products, day-over-day %) is computed directly from the CSV in Python.
Claude is only asked to write the opening paragraph of prose *describing*
those already-computed numbers — it never invents or recalculates a figure.
If `ANTHROPIC_API_KEY` isn't set (or the API call fails), the agent still
sends a full report using a plain-template paragraph instead. A report
always goes out.

## 1. Install

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

## 2. Configure

```bash
cp .env.example .env
```

Edit `.env`:

| Variable | Required | Notes |
|---|---|---|
| `SALES_CSV_PATH` | yes | Path to the CSV your export job writes each morning |
| `SMTP_HOST`, `SMTP_PORT` | yes | Your mail provider's SMTP settings (587 = STARTTLS) |
| `SMTP_USERNAME`, `SMTP_PASSWORD` | yes | For Gmail, use an [App Password](https://myaccount.google.com/apppasswords), not your login password |
| `EMAIL_FROM` | yes | Sender address |
| `EMAIL_TO` | yes | Comma-separated recipient list |
| `ANTHROPIC_API_KEY` | no | Enables the narrative paragraph. Get one at console.anthropic.com |

### Expected CSV shape

One row per sale. Column names are case-insensitive; only `quantity` is
strictly required — everything else is used if present:

```
date, product, category, region, quantity, unit_price
```

- If a `revenue`/`total`/`sales`/`amount` column exists, it's used as-is;
  otherwise revenue is derived as `quantity * unit_price`.
- If `date` has more than one distinct day in the file, the agent reports
  on the most recent day and shows % change vs. the day before it.
- Missing `product`/`region` columns just skip that section of the report.

See `sample_sales.csv` for a working example.

## 4. Schedule it to run every morning

### Windows (Task Scheduler)

Run once from an elevated PowerShell to register a daily 7:00 AM task
(adjust the time and paths):

```powershell
$python = "C:\tmp\skills-eval\arm-a\t13-r2\sales-report-agent\.venv\Scripts\python.exe"
$script = "C:\tmp\skills-eval\arm-a\t13-r2\sales-report-agent\sales_summary_agent.py"

schtasks /create /tn "DailySalesSummary" /tr "`"$python`" `"$script`"" /sc daily /st 07:00 /f
```

- `/f` overwrites an existing task with the same name (safe to re-run).
- Check it ran: `schtasks /query /tn "DailySalesSummary" /v /fo list`
- Remove it: `schtasks /delete /tn "DailySalesSummary" /f`
- Task Scheduler runs with the task owner's environment, not your shell's —
  keep secrets in `.env` (loaded via `python-dotenv`) rather than relying on
  env vars set in your terminal session.

## Troubleshooting

- **"CSV is missing required column(s)"** — your export needs at least a
  `quantity` column; check the header row.
- **SMTP auth errors** — most providers (Gmail, Outlook) require an
  app-specific password when 2FA is on; a regular login password will fail.
- **No narrative paragraph, just numbers** — `ANTHROPIC_API_KEY` isn't set,
  or the API call failed; check the log line printed at startup. The report
  still sends either way.
- **Email didn't arrive** — run with `--dry-run` first to confirm the CSV
  parses correctly, then check spam and that `EMAIL_TO` has no typos.
````

````py
"""
Daily Sales Summary Agent
=========================

Reads the daily sales CSV, computes the day's numbers with pandas (the
numbers you can trust), optionally asks Claude for a short, friendly
narrative paragraph on top of those numbers, and emails the result to the
team.

Design notes:
  - All figures in the email (totals, top products, % change) are computed
    directly from the CSV with pandas. Claude is only ever asked to write
    prose *about* numbers it is given -- it never invents or re-derives a
    number, so the report can't drift from the data.
  - If ANTHROPIC_API_KEY isn't set, the agent still sends a complete report
    using a plain template instead of the narrative paragraph. A missing
    API key should never mean the team gets no report.
  - Designed to be run once per day by a scheduler (Windows Task Scheduler,
    cron, etc.) -- see README.md for setup.

Usage:
    python sales_summary_agent.py [--csv PATH] [--dry-run]

    --dry-run   Print the email instead of sending it (no SMTP connection).
"""

from __future__ import annotations

import argparse
import logging
import os
import smtplib
import sys
from dataclasses import dataclass, field
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from pathlib import Path

import pandas as pd
from dotenv import load_dotenv

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
)
log = logging.getLogger("sales_summary_agent")


# --------------------------------------------------------------------------
# Data loading & analysis
# --------------------------------------------------------------------------

REQUIRED_COLUMNS = {"quantity"}  # the bare minimum we can still report on


@dataclass
class DaySummary:
    report_date: str | None
    total_revenue: float
    total_units: int
    num_transactions: int
    avg_order_value: float
    top_products: list[tuple[str, float]]  # (name, revenue)
    top_regions: list[tuple[str, float]]  # (name, revenue)
    prev_revenue: float | None = None
    prev_units: int | None = None
    revenue_pct_change: float | None = None
    units_pct_change: float | None = None
    warnings: list[str] = field(default_factory=list)


def load_sales_csv(path: Path) -> pd.DataFrame:
    if not path.exists():
        raise FileNotFoundError(f"Sales CSV not found: {path}")
    df = pd.read_csv(path)
    df.columns = [c.strip().lower() for c in df.columns]
    missing = REQUIRED_COLUMNS - set(df.columns)
    if missing:
        raise ValueError(
            f"CSV is missing required column(s): {sorted(missing)}. "
            f"Found columns: {list(df.columns)}"
        )
    return df


def _pct_change(new: float, old: float) -> float | None:
    if old in (0, None):
        return None
    return (new - old) / old * 100.0


def summarize(df: pd.DataFrame) -> DaySummary:
    warnings: list[str] = []

    # Revenue: use an existing revenue/total/sales column if present,
    # otherwise derive it from quantity * unit_price.
    revenue_col = next(
        (c for c in ("revenue", "total", "sales", "amount") if c in df.columns), None
    )
    if revenue_col is None:
        if "unit_price" in df.columns:
            df = df.copy()
            df["revenue"] = df["quantity"] * df["unit_price"]
            revenue_col = "revenue"
        else:
            warnings.append(
                "No revenue/total column and no unit_price column found -- "
                "revenue figures are unavailable, reporting units only."
            )
            df = df.copy()
            df["revenue"] = 0.0
            revenue_col = "revenue"

    # Restrict to the most recent date if a date column exists and has
    # more than one distinct day in it (comparison uses the second-most-recent).
    report_date = None
    prev_revenue = prev_units = None
    today_df = df
    if "date" in df.columns:
        df = df.copy()
        df["date"] = pd.to_datetime(df["date"], errors="coerce")
        if df["date"].isna().all():
            warnings.append("'date' column present but unparseable -- ignoring it.")
        else:
            distinct_dates = sorted(df["date"].dropna().unique())
            latest = distinct_dates[-1]
            report_date = pd.Timestamp(latest).strftime("%Y-%m-%d")
            today_df = df[df["date"] == latest]
            if len(distinct_dates) > 1:
                prev_date = distinct_dates[-2]
                prev_df = df[df["date"] == prev_date]
                prev_revenue = float(prev_df[revenue_col].sum())
                prev_units = int(prev_df["quantity"].sum())

    total_revenue = float(today_df[revenue_col].sum())
    total_units = int(today_df["quantity"].sum())
    num_transactions = int(len(today_df))
    avg_order_value = total_revenue / num_transactions if num_transactions else 0.0

    top_products: list[tuple[str, float]] = []
    if "product" in today_df.columns:
        grouped = (
            today_df.groupby("product")[revenue_col]
            .sum()
            .sort_values(ascending=False)
            .head(5)
        )
        top_products = list(grouped.items())

    top_regions: list[tuple[str, float]] = []
    if "region" in today_df.columns:
        grouped = (
            today_df.groupby("region")[revenue_col]
            .sum()
            .sort_values(ascending=False)
            .head(5)
        )
        top_regions = list(grouped.items())

    return DaySummary(
        report_date=report_date,
        total_revenue=total_revenue,
        total_units=total_units,
        num_transactions=num_transactions,
        avg_order_value=avg_order_value,
        top_products=top_products,
        top_regions=top_regions,
        prev_revenue=prev_revenue,
        prev_units=prev_units,
        revenue_pct_change=_pct_change(total_revenue, prev_revenue)
        if prev_revenue is not None
        else None,
        units_pct_change=_pct_change(total_units, prev_units)
        if prev_units is not None
        else None,
        warnings=warnings,
    )


# --------------------------------------------------------------------------
# Narrative (optional Claude call)
# --------------------------------------------------------------------------

def build_narrative(summary: DaySummary) -> str | None:
    """Ask Claude for a short, friendly paragraph describing the numbers.

    Returns None (caller falls back to a template) if no API key is set or
    the call fails for any reason -- a report always goes out either way.
    """
    if not os.environ.get("ANTHROPIC_API_KEY"):
        log.info("ANTHROPIC_API_KEY not set -- skipping narrative, using template.")
        return None

    try:
        import anthropic
    except ImportError:
        log.warning("anthropic package not installed -- skipping narrative.")
        return None

    stats_payload = {
        "report_date": summary.report_date,
        "total_revenue": round(summary.total_revenue, 2),
        "total_units": summary.total_units,
        "num_transactions": summary.num_transactions,
        "avg_order_value": round(summary.avg_order_value, 2),
        "top_products": summary.top_products,
        "top_regions": summary.top_regions,
        "revenue_pct_change_vs_prev_day": summary.revenue_pct_change,
        "units_pct_change_vs_prev_day": summary.units_pct_change,
    }

    client = anthropic.Anthropic()
    try:
        response = client.messages.create(
            model="claude-opus-5",
            max_tokens=400,
            output_config={"effort": "low"},  # simple prose task, keep it cheap
            system=(
                "You write the opening paragraph of a daily sales summary "
                "email for an internal team. You will be given the exact "
                "computed figures as JSON -- use ONLY those numbers, do not "
                "invent or recompute anything. Write 3-5 sentences, friendly "
                "and direct, highlighting the headline number, the standout "
                "product/region, and the day-over-day change if given. No "
                "greeting, no sign-off, no subject line -- just the paragraph."
            ),
            messages=[
                {"role": "user", "content": str(stats_payload)},
            ],
        )
    except anthropic.RateLimitError as e:
        log.warning("Claude rate-limited (%s) -- using template instead.", e)
        return None
    except anthropic.APIStatusError as e:
        log.warning("Claude API error %s -- using template instead.", e.status_code)
        return None
    except anthropic.APIConnectionError as e:
        log.warning("Claude connection error (%s) -- using template instead.", e)
        return None

    if response.stop_reason == "refusal":
        log.warning("Claude declined to answer -- using template instead.")
        return None

    text = next((b.text for b in response.content if b.type == "text"), None)
    return text.strip() if text else None


def template_narrative(summary: DaySummary) -> str:
    parts = [
        f"Total revenue was ${summary.total_revenue:,.2f} across "
        f"{summary.num_transactions} transactions ({summary.total_units} units)."
    ]
    if summary.revenue_pct_change is not None:
        direction = "up" if summary.revenue_pct_change >= 0 else "down"
        parts.append(
            f"That's {direction} {abs(summary.revenue_pct_change):.1f}% vs. the previous day."
        )
    if summary.top_products:
        name, rev = summary.top_products[0]
        parts.append(f"Top product: {name} (${rev:,.2f}).")
    return " ".join(parts)


# --------------------------------------------------------------------------
# Email formatting & sending
# --------------------------------------------------------------------------

def build_email_body(summary: DaySummary, narrative: str) -> tuple[str, str]:
    """Returns (plain_text, html)."""
    date_label = summary.report_date or "latest data"

    lines = [narrative, "", f"Report date: {date_label}", ""]
    lines.append(f"Total revenue:      ${summary.total_revenue:,.2f}")
    lines.append(f"Units sold:         {summary.total_units}")
    lines.append(f"Transactions:       {summary.num_transactions}")
    lines.append(f"Avg order value:    ${summary.avg_order_value:,.2f}")
    if summary.revenue_pct_change is not None:
        lines.append(f"Revenue vs prev day: {summary.revenue_pct_change:+.1f}%")
    if summary.units_pct_change is not None:
        lines.append(f"Units vs prev day:   {summary.units_pct_change:+.1f}%")

    if summary.top_products:
        lines.append("")
        lines.append("Top products by revenue:")
        for name, rev in summary.top_products:
            lines.append(f"  - {name}: ${rev:,.2f}")

    if summary.top_regions:
        lines.append("")
        lines.append("Top regions by revenue:")
        for name, rev in summary.top_regions:
            lines.append(f"  - {name}: ${rev:,.2f}")

    if summary.warnings:
        lines.append("")
        lines.append("Notes:")
        for w in summary.warnings:
            lines.append(f"  - {w}")

    plain_text = "\n".join(lines)

    def row(label, value):
        return f"<tr><td style='padding:4px 12px 4px 0;color:#555'>{label}</td><td style='padding:4px 0;font-weight:600'>{value}</td></tr>"

    stat_rows = [
        row("Total revenue", f"${summary.total_revenue:,.2f}"),
        row("Units sold", summary.total_units),
        row("Transactions", summary.num_transactions),
        row("Avg order value", f"${summary.avg_order_value:,.2f}"),
    ]
    if summary.revenue_pct_change is not None:
        stat_rows.append(row("Revenue vs prev day", f"{summary.revenue_pct_change:+.1f}%"))
    if summary.units_pct_change is not None:
        stat_rows.append(row("Units vs prev day", f"{summary.units_pct_change:+.1f}%"))

    product_rows = "".join(
        f"<li>{name}: ${rev:,.2f}</li>" for name, rev in summary.top_products
    )
    region_rows = "".join(
        f"<li>{name}: ${rev:,.2f}</li>" for name, rev in summary.top_regions
    )

    html = f"""\
<html>
<body style="font-family:Arial,Helvetica,sans-serif;color:#222;line-height:1.5">
  <h2 style="margin-bottom:4px">Daily Sales Summary &mdash; {date_label}</h2>
  <p>{narrative}</p>
  <table cellspacing="0" cellpadding="0">{''.join(stat_rows)}</table>
  {"<h3>Top products</h3><ul>" + product_rows + "</ul>" if product_rows else ""}
  {"<h3>Top regions</h3><ul>" + region_rows + "</ul>" if region_rows else ""}
  {"<p style='color:#a00;font-size:0.9em'>" + "<br>".join(summary.warnings) + "</p>" if summary.warnings else ""}
</body>
</html>"""

    return plain_text, html


def send_email(subject: str, plain_text: str, html: str) -> None:
    smtp_host = os.environ["SMTP_HOST"]
    smtp_port = int(os.environ.get("SMTP_PORT", "587"))
    smtp_user = os.environ["SMTP_USERNAME"]
    smtp_password = os.environ["SMTP_PASSWORD"]
    email_from = os.environ.get("EMAIL_FROM", smtp_user)
    recipients = [addr.strip() for addr in os.environ["EMAIL_TO"].split(",") if addr.strip()]

    if not recipients:
        raise ValueError("EMAIL_TO is empty -- no recipients to send to.")

    msg = MIMEMultipart("alternative")
    msg["Subject"] = subject
    msg["From"] = email_from
    msg["To"] = ", ".join(recipients)
    msg.attach(MIMEText(plain_text, "plain"))
    msg.attach(MIMEText(html, "html"))

    with smtplib.SMTP(smtp_host, smtp_port, timeout=30) as server:
        server.starttls()
        server.login(smtp_user, smtp_password)
        server.sendmail(email_from, recipients, msg.as_string())

    log.info("Email sent to %s", ", ".join(recipients))


# --------------------------------------------------------------------------
# Entry point
# --------------------------------------------------------------------------

def main() -> int:
    load_dotenv()

    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument(
        "--csv",
        type=Path,
        default=None,
        help="Path to the sales CSV (defaults to SALES_CSV_PATH env var).",
    )
    parser.add_argument(
        "--dry-run",
        action="store_true",
        help="Print the report instead of emailing it.",
    )
    args = parser.parse_args()

    csv_path = args.csv or Path(os.environ.get("SALES_CSV_PATH", "./sample_sales.csv"))

    try:
        df = load_sales_csv(csv_path)
    except (FileNotFoundError, ValueError) as e:
        log.error("Could not load sales data: %s", e)
        return 1

    summary = summarize(df)
    for w in summary.warnings:
        log.warning(w)

    narrative = build_narrative(summary) or template_narrative(summary)
    plain_text, html = build_email_body(summary, narrative)

    date_label = summary.report_date or "Today"
    subject_prefix = os.environ.get("EMAIL_SUBJECT_PREFIX", "[Daily Sales Summary]")
    subject = f"{subject_prefix} {date_label} - ${summary.total_revenue:,.2f}"

    if args.dry_run:
        print(f"Subject: {subject}\n")
        print(plain_text)
        return 0

    try:
        send_email(subject, plain_text, html)
    except KeyError as e:
        log.error("Missing required email config: %s. Check your .env file.", e)
        return 1
    except smtplib.SMTPException as e:
        log.error("Failed to send email: %s", e)
        return 1

    return 0


if __name__ == "__main__":
    sys.exit(main())
````
