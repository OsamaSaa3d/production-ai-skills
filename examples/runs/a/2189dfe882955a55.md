- `get_inventory(sku)` and `reserve_stock(sku, qty)` can raise on failure — I catch exceptions and turn them into `{"error": ...}` results so Claude sees a clear failure message instead of a crash.
- `qty` should be a positive int — validated before calling `reserve_stock`.

**How it works:**
1. `check_inventory` and `reserve_inventory` are thin wrappers around your functions, decorated with `@beta_tool`. The decorator derives the JSON tool schema straight from the type hints and docstring (`sku: str`, `qty: int`), so there's no manual schema to maintain.
2. `client.beta.messages.tool_runner(...)` drives the full request → tool-call → result → next request loop for you — no manual `while stop_reason == "tool_use"` loop needed.
3. `run(user_message)` feeds in a prompt and returns Claude's final text once it reaches `end_turn`.

Model defaults to `claude-opus-5` per this project's guidance (override via the `model=` param if you want Sonnet/Haiku for cheaper/faster calls). Note: the tool runner is a **beta** SDK feature — fine for most uses, but if you need to avoid beta dependencies, say so and I'll convert it to a manual loop instead.

````py
"""
Lets Claude call your existing get_inventory(sku) and reserve_stock(sku, qty)
functions as tools, using the Anthropic SDK's beta tool runner.

Adjust the import below to point at wherever get_inventory/reserve_stock
actually live in your codebase.
"""

import anthropic
from anthropic import beta_tool

from inventory_service import get_inventory, reserve_stock  # <-- your existing functions


@beta_tool
def check_inventory(sku: str) -> dict:
    """Look up current stock for a SKU.

    Args:
        sku: The product SKU to look up, e.g. "WIDGET-42".
    """
    try:
        result = get_inventory(sku)
    except Exception as e:
        return {"error": f"Could not look up inventory for {sku!r}: {e}"}
    return {"sku": sku, "inventory": result}


@beta_tool
def reserve_inventory(sku: str, qty: int) -> dict:
    """Reserve a quantity of stock for a SKU.

    Args:
        sku: The product SKU to reserve, e.g. "WIDGET-42".
        qty: Number of units to reserve. Must be a positive integer.
    """
    if qty <= 0:
        return {"error": f"qty must be positive, got {qty}"}
    try:
        result = reserve_stock(sku, qty)
    except Exception as e:
        return {"error": f"Could not reserve {qty} of {sku!r}: {e}"}
    return {"sku": sku, "qty": qty, "reservation": result}


def run(user_message: str, model: str = "claude-opus-5") -> str:
    """Send one user message through the tool loop and return Claude's final text."""
    client = anthropic.Anthropic()

    runner = client.beta.messages.tool_runner(
        model=model,
        max_tokens=16000,
        tools=[check_inventory, reserve_inventory],
        messages=[{"role": "user", "content": user_message}],
    )

    final_text = ""
    for message in runner:
        if message.stop_reason == "end_turn":
            final_text = next(
                (b.text for b in message.content if b.type == "text"), ""
            )

    return final_text


if __name__ == "__main__":
    reply = run("Do we have 10 units of SKU WIDGET-42 in stock? If so, reserve them.")
    print(reply)

````
