**How it works:**
1. `run_sql_query` is a `@beta_tool`-decorated function — the only thing Claude can do to touch your data. It's given to `client.beta.messages.tool_runner`, which runs the full ask → generate SQL → execute → read results → answer loop for you.
2. The system prompt gives Claude the exact `orders` schema and rules (SELECT-only, LIMIT, correct quoting).
3. Claude calls `run_sql_query` with SQL it writes; the tool executes it on a **read-only transaction** with a 5s `statement_timeout` and a 500-row fetch cap, then returns JSON rows back to Claude.
4. Claude reads the rows and answers in plain English with real numbers.

**Model/params used, per current guidance:** `claude-opus-5` (current default model), the beta tool runner (`client.beta.messages.tool_runner` + `@beta_tool`) rather than a hand-rolled loop, `max_tokens=4096` (plenty for a data-analyst answer), and a most-specific-first exception chain (`RateLimitError` → `APIStatusError` → `APIConnectionError`).

**Security notes (important since Claude is writing arbitrary SQL):**
- The regex/keyword checks in `run_sql_query` are defense-in-depth only, not the real boundary. **Point `DATABASE_URL` at a Postgres role that only has `SELECT` on `orders`** — that's what actually stops a bad query from mutating data.
- Query runs in `readonly=True` + `SET LOCAL statement_timeout` so a runaway or accidental heavy query can't hang the DB.
- Semicolon/keyword blocking prevents basic statement-stacking tricks.

"""
Ask plain-English questions about the `orders` table and get an answer.

Claude turns the question into a read-only SQL SELECT, a tool executes it
against Postgres, and Claude summarizes the result in plain English.

    orders(id, customer_email, status, total_usd, placed_at)

Setup
-----
    pip install -r requirements.txt

    export ANTHROPIC_API_KEY=sk-ant-...       # or `ant auth login`
    export DATABASE_URL=postgresql://readonly_user:pw@host:5432/dbname

Strongly recommended: point DATABASE_URL at a Postgres role that only has
SELECT on `orders` (e.g. `CREATE ROLE readonly_user LOGIN PASSWORD '...';
GRANT SELECT ON orders TO readonly_user;`). The checks in run_sql_query are
defense in depth, not a substitute for real DB permissions - an LLM-written
query is still untrusted input.

Usage
-----
    python ask_orders.py "How much revenue came from shipped orders last week?"

    # or, with no arguments, an interactive prompt:
    python ask_orders.py
"""

import json
import os
import re
import sys

import anthropic
import psycopg2
import psycopg2.extras
from anthropic import beta_tool

MODEL = "claude-opus-5"

SCHEMA = """
Table: orders
  id              bigint, primary key
  customer_email  text
  status          text     -- e.g. 'pending', 'paid', 'shipped', 'cancelled', 'refunded'
  total_usd       numeric
  placed_at       timestamptz
"""

SYSTEM_PROMPT = f"""You are a data analyst with read-only access to one Postgres
table, reachable only through the `run_sql_query` tool.
{SCHEMA}
Rules:
- Issue a single SELECT statement per call (CTEs and window functions are fine).
  Never write INSERT, UPDATE, DELETE, or any DDL.
- Only reference the `orders` table and the columns listed above.
- Add LIMIT 100 unless the question calls for a single aggregate row
  (COUNT, SUM, AVG, ...).
- Use ISO date literals and Postgres-correct quoting.
- If a call fails or is rejected, read the error and try a corrected query.
- Once you have results, answer in plain English with the actual numbers -
  don't just say "yes" or dump a table.
- If the question can't be answered from this table, say so plainly.
"""

# Belt-and-suspenders guard around whatever SQL the model writes. Real
# enforcement should come from a read-only DB role (see module docstring).
_SINGLE_STATEMENT = re.compile(r"^\s*(select|with)\b", re.IGNORECASE)
_FORBIDDEN_KEYWORDS = re.compile(
    r"\b(insert|update|delete|drop|alter|truncate|grant|revoke|create|call|copy|"
    r"vacuum|reindex|execute|do)\b",
    re.IGNORECASE,
)
ROW_CAP = 500
STATEMENT_TIMEOUT_MS = 5_000


def _get_connection():
    return psycopg2.connect(os.environ["DATABASE_URL"])


@beta_tool
def run_sql_query(sql: str) -> str:
    """Run one read-only SQL SELECT statement against the `orders` table.

    Args:
        sql: A single Postgres SELECT (or WITH ... SELECT) statement. No
            semicolon-separated statements, no INSERT/UPDATE/DELETE/DDL.

    Returns:
        A JSON string: either a list of row objects, or {"error": "..."}.
    """
    statement = sql.strip().rstrip(";")

    if ";" in statement:
        return json.dumps({"error": "Only a single statement is allowed."})
    if not _SINGLE_STATEMENT.match(statement):
        return json.dumps({"error": "Only SELECT/WITH statements are allowed."})
    if _FORBIDDEN_KEYWORDS.search(statement):
        return json.dumps({"error": "Statement contains a disallowed keyword."})

    try:
        conn = _get_connection()
        try:
            conn.set_session(readonly=True, autocommit=False)
            with conn:
                with conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor) as cur:
                    cur.execute("SET LOCAL statement_timeout = %s", (STATEMENT_TIMEOUT_MS,))
                    cur.execute(statement)
                    rows = cur.fetchmany(ROW_CAP)
            return json.dumps(rows, default=str)
        finally:
            conn.close()
    except psycopg2.Error as e:
        return json.dumps({"error": str(e).strip()})


def ask(question: str) -> str:
    client = anthropic.Anthropic()

    try:
        runner = client.beta.messages.tool_runner(
            model=MODEL,
            max_tokens=4096,
            system=SYSTEM_PROMPT,
            tools=[run_sql_query],
            messages=[{"role": "user", "content": question}],
        )

        final_text = ""
        for message in runner:
            for block in message.content:
                if block.type == "text":
                    final_text = block.text
        return final_text or "(Claude returned no text answer.)"

    except anthropic.RateLimitError:
        return "Rate limited - please try again shortly."
    except anthropic.APIStatusError as e:
        return f"API error ({e.status_code}): {e.message}"
    except anthropic.APIConnectionError:
        return "Network error talking to the Claude API."


def main() -> None:
    if len(sys.argv) > 1:
        print(ask(" ".join(sys.argv[1:])))
        return

    print("Ask questions about the orders table (Ctrl+C to quit).")
    while True:
        try:
            question = input("\n> ").strip()
        except (EOFError, KeyboardInterrupt):
            break
        if question:
            print(ask(question))


if __name__ == "__main__":
    main()
